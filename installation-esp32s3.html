ESP32-S3 Installation Guide

Hardware wiring and first-start instructions for the current SIGVERN RF ESP32-S3 N16R8 reference build. This guide intentionally contains no wiring image: use the pin table below.

Install from the browser

Connect the ESP32-S3 with a USB data cable, then choose the serial port in the installer. The installer writes the matching v2.0.0-beta.3 firmware and LittleFS images in one step.

Before you start: a fresh installation can erase the entire flash. Export a backup first if the device already contains Wi-Fi, MQTT or saved slot data.

Use desktop Chrome, Edge or Firefox. iPhone/iPad browsers cannot use USB serial installation.

Required hardware

  • ESP32-S3 N16R8 (16 MB Flash, 8 MB PSRAM)
  • Two CC1101 modules: one suitable for 433 MHz and one for 868 MHz
  • A correctly tuned 433 MHz or 868 MHz antenna
  • USB data cable
Power requirement: Power the CC1101 from a regulated 3.3 V supply only. Never connect the CC1101 VCC pin to 5 V. The CC1101 and ESP32-S3 must share a common GND.

Connect both radios to the shared SPI pins shown above. RF1 is configured for 433 MHz and RF2 for 868 MHz; use matching modules and antennas.

Build and upload with PlatformIO

  1. Download or clone the current ESP32-S3 source and open the project folder in Visual Studio Code with PlatformIO.
  2. Verify that the esp32s3 environment is selected in platformio.ini.
  3. Run Build.
  4. Connect the ESP32-S3 by USB and run Upload.
  5. Run Upload Filesystem Image when installing the WebUI for the first time or when the data/ files have changed.

Release binaries

The v2.0.0-beta.3 GitHub release provides matching ESP32-S3 firmware and LittleFS images. Keep firmware and LittleFS from the same release together.

  • SIGVERN-RF-v2.0.0-beta.3-ESP32S3-firmware.bin
  • SIGVERN-RF-v2.0.0-beta.3-ESP32S3-littlefs.bin
Important: A normal Upload Filesystem Image / uploadfs replaces the entire LittleFS, including Wi-Fi and MQTT settings and saved slots. Export a backup first. After uploading both images, reconnect to SIGVERN-RF-Setup at 192.168.4.1 and restore the backup.

First start

  1. Power on or restart the ESP32-S3 after flashing.
  2. Connect to the SIGVERN-RF-Setup Wi-Fi access point.
  3. Open 192.168.4.1 in a browser.
  4. Configure Wi-Fi and MQTT, then save the settings.
  5. Allow the device to restart and open the IP address assigned by your local network.
  6. On the Settings page select 433 MHz (433.920 MHz) or 868 MHz (868.350 MHz) to match your CC1101 module and antenna, then restart if requested.
Frequency note: Changing the frequency in software does not retune the antenna or RF matching network. Use hardware designed for the selected band.
