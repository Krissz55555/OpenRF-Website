SIGVERN RF v2.0.0-beta.3

The ESP32-S3 generation is here.

SIGVERN RF v2.0.0-beta.3 brings the proven RF gateway, Analyzer, RAW Learn & Replay, MQTT and Home Assistant feature set to ESP32-S3 N16R8. The new architecture adds dual-core task separation, 8 MB PSRAM support and significantly more processing and memory headroom.

The ESP8266 v1.2.0 edition remains available as a feature-complete legacy release. The ESP32-S3 branch is now the active SIGVERN RF platform.

v2.0.0-beta.3 highlights

The proven SIGVERN RF feature set, now on ESP32-S3.

The first public ESP32-S3 beta preserves the existing RF workflow while adding dual-core execution, PSRAM-aware buffering and substantially more hardware headroom.

⚙

ESP32-S3 Dual-Core

FreeRTOS task separation keeps RF processing apart from the main application workload for smoother concurrent operation.

▣

8 MB PSRAM

Large non-critical RAW, Learn and Analyzer work buffers can use PSRAM while time-critical RF data remains in internal RAM.

🔍

RF Analyzer v2

The Analyzer is non-exclusive on ESP32-S3 and can run alongside RX Slots, MQTT, Home Assistant and normal gateway operation.

↻

RAW Learn & Replay

Capture unknown RF pulse trains, preview them, save them to persistent TX slots and replay them when needed.

◎

Universal RX Slots

Store decoded RF event identities and expose recognised events through MQTT and Home Assistant workflows.

🧩

Native Protocol Framework

Structured protocol support includes native NVKP01 Kinetic decoding and provides a foundation for additional protocols.

⌂

MQTT & Home Assistant

Configurable MQTT, event publication and Home Assistant Discovery remain integrated into the local SIGVERN RF workflow.

⇧

OTA, Backup & Restore

Update firmware from the WebUI and protect device configuration with integrated backup and restore tools.

◫

433 / 868 MHz Selection

Two CC1101 radios support simultaneous 433.920 and 868.350 MHz operation with suitable modules and antennas.

◉

Live System Diagnostics

The WebUI exposes CPU and memory information together with Flash, PSRAM and internal heap diagnostics.

Development roadmap

Dual-radio SIGVERN RF is available. Next comes the Deep Analyzer.

v2.0.0-beta.3 supports two CC1101 radios for simultaneous 433 and 868 MHz operation. Deep Analyzer development is planned next and has not started.
